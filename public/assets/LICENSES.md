# Asset licences

Every file under `public/assets/` comes from one of the packs below. Raw downloads stay in
`assets/_raw/`, which is gitignored and never shipped.

## Icons: `icons/*.png` (Raven Fantasy Icons, free version)

- **Author:** Clockwork Raven Studios (Caio). Source: https://clockworkraven.itch.io/raven-fantasy-icons
- **Licence (free version), from the itch.io page, checked 2026-09-30:** personal use only.
  "Personal use includes any projects or game released for free with no microtransactions and/or
  paid advertisement/ad." The asset "cannot be distributed or sold as a separate product without the
  creator's permission." "Attribution is not necessary but welcome." The asset "can be modified to
  match any of your needs." The full licence text is in a Google Drive folder linked from the page.
- **What this means for Quartermaster:** shipping these icons inside a free game with no ads and no
  microtransactions is allowed. Don't publish the icons on their own (for example as a sprite pack).
  **If the game is ever sold, carries ads, or has microtransactions, buy the premium version first;**
  its licence allows commercial use.
- **Credit (given voluntarily):** "Icons: Raven Fantasy Icons by Clockwork Raven Studios."

## Not shipped: MedievalFantasyFree (ToffeeCraft free UI sheets)

`assets/_raw/MedievalFantasyFree/` holds `FreeUI.png`, `MediavelFree.png` and `FreeFairyTaleUI.png`.
`FreeFairyTaleUI` is ToffeeCraft's *Fairytale UI Pack* free tier
(https://toffeecraft.itch.io/fairytale-ui-pack). The other two sheets match its style and were
downloaded in the same browser session, so they are almost certainly ToffeeCraft free tiers too,
for example from the UI Mega Pack (https://toffeecraft.itch.io/ui-user-interface-mega-pack). The
ToffeeCraft free licence reads: "For personal use. It can be used and edit freely. Not redistribute
or resell this assets." **None of these files are in `public/assets/`.** A hosted web game serves
its files to every visitor, which is redistribution. The paid tier allows commercial use but has the
same no-redistribution clause, so buy it and confirm the terms with the author before shipping any of it.
